# 坦克大战（Battle City）

一个使用原生 HTML5 Canvas + JavaScript 编写的经典坦克大战小游戏，单个 `index.html` 文件即可运行，无需任何依赖。

## 玩法

- 控制你的金色坦克，**守住屏幕下方的基地（老鹰）**
- 消灭不断来袭的敌军坦克，坚持尽可能多的关卡
- 基地被摧毁或生命耗尽则游戏结束

## 操作

| 按键 | 功能 |
| --- | --- |
| `WASD` / `方向键` | 移动坦克 |
| `空格` / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `M` | 静音 / 取消静音 |

移动端也提供了触屏虚拟按键。

## 特性

- 经典砖墙 / 钢墙地形，砖墙可被击毁，钢墙不可穿透
- 逐关递增的敌军数量与难度
- 道具系统：`♥` 增加生命，`★` 强化弹药（可击穿钢墙）
- 粒子爆炸特效、屏幕震动、Web Audio 音效
- 最高分本地记录（localStorage）

## 运行

直接用浏览器打开 `index.html` 即可，或部署到任意静态托管服务：

```bash
# 本地起一个简单服务器（可选）
npx serve .
```
